# بوت واتساب Rust

بوت واتساب غير رسمي مبني على [`whatsapp-rust`](https://github.com/oxidezap/whatsapp-rust).

تم دمج مكتبة [`rusty_ytdl`](https://github.com/Mithronn/rusty_ytdl) لتنزيل فيديوهات وصوت يوتيوب مباشرة عبر واتساب، من دون `yt-dlp` أو الحاجة إلى `ffmpeg`.

> هذا العميل غير رسمي وقد يخالف شروط WhatsApp. استخدمه على مسؤوليتك.

## المتطلبات

- Rust وCargo مثبتان مسبقًا على الخادم، مع دعم Rust Edition 2024.
- اتصال إنترنت.
- رقم WhatsApp دولي في ملف `.env`.

## الإعداد

أنشئ ملف `.env` في جذر المشروع:

```dotenv
WHATSAPP_PHONE_NUMBER=9665XXXXXXXX
```

لا ترفع `.env` أو `whatsapp_bot.db` إلى مستودع عام.

## التشغيل

```bash
cargo run --release
```

سيظهر pairing code في الطرفية. بعد الربط تُحفظ الجلسة في `whatsapp_bot.db`.

## أوامر البوت

- `/hi` — اختبار بسيط.
- `/ping` — التحقق من أن البوت يعمل.
- `/echo <نص>` — إعادة إرسال النص.
- `/yt <رابط يوتيوب>` — تنزيل مسار الفيديو فقط بأقل جودة متاحة مناسبة للإرسال.
- `/ytaudio <رابط يوتيوب>` — تنزيل المسار الصوتي فقط كملف صوتي.
- `/sendfile <المسار> [تعليق]` — رفع ملف محلي وإرساله كمستند في المحادثة. الحد الأقصى لحجم الملف 1000 MB.
- `/help` أو `/مساعدة` — عرض قائمة الأوامر.

أي رسالة أخرى لا تطابق أمرًا مدعومًا لا ينتج عنها رد. تُحفظ التنزيلات مؤقتًا في مجلد النظام ثم تُحذف بعد الإرسال.

### ملاحظات تنزيل يوتيوب

- يجب أن يكون الرابط عامًا وغير محمي أو خاصًا.
- يحد المشروع حجم الملف الناتج إلى 1000 MB قبل رفعه إلى واتساب.
- قد يفشل التنزيل عند حظر يوتيوب أو تجاوز معدل الطلبات؛ هذه قيود في المصدر وليست في واتساب.
- تُستخدم نسخة rusty_ytdl من فرع `main` للحصول على إصلاحات استخراج يوتيوب الحالية، ولا توجد أي حاجة إلى `ffmpeg`.
- لا يتم دمج مساري الفيديو والصوت؛ لذلك لا يحتاج المشروع إلى `ffmpeg`.
- عند رفض صيغة فيديو من خادم `googlevideo` بحالة `403`، يجرب البوت صيغة بديلة تلقائيًا مع نطاق تنزيل أصغر.

### مثال على إرسال ملف

```text
/sendfile /home/ubuntu/files/report.pdf التقرير الشهري
```

يُرسل البوت الملف إلى نفس المحادثة التي استقبل فيها الأمر. يجب أن يكون المسار متاحًا للعملية، والمسارات التي تحتوي على مسافات غير مدعومة في الصيغة الحالية.

## ملاحظات أمنية

- pairing code وملف قاعدة البيانات بيانات حساسة.
- لا تشارك ملف `.env` أو رقم الهاتف في مستودع عام.
